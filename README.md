# SACREPS-SHOP

Tienda de demostración de SACREPS construida con Vite, React, GSAP y Lucide.

## Desarrollo

```sh
npm install
npm run dev
```

Genera una compilación de producción con `npm run build`.

## Catálogo y pedidos

El catálogo y los precios iniciales son demostrativos y se editan en `src/App.jsx`. Todos los productos tienen envío gratis; el checkout usa pago contra entrega y envía los datos del pedido a `https://formspree.io/f/xgaaoeba`. Verifica los datos de prueba, inventario, precios y la configuración de Formspree antes de aceptar pedidos reales. No se deben publicar medicamentos sin validar sus requisitos regulatorios.
